CourseAgent Studio

Turn a course syllabus into a governed course agent. Design it for Muse and any agent platform, charter it with the AGENT Framework, and publish it with its guardrails attached.

Muse first Governance first Hint-only tutoring Syllabus-bound answers

Start with the syllabus

The agent may only teach what is here. If a topic is not in the syllabus, the agent refuses and escalates. That boundary is the product.

Format: Title: details. The details are the agent's only source material for that topic.

The sample is a fictional course (BIO 210 at the fictional Northgate College), included so you can test the studio in one click.

Final step: create your agent in Muse

      
Copy the final output below and paste it into Muse. Your teaching assistant agent is created from this package. The package holds everything Muse needs, in three sections: who your agent is (its soul: name, identity, character, values, never-do rules, and voice), what your agent does (the system prompt and the syllabus grounding the agent is allowed to teach from), and where the instructor stays in charge (the full AGENT Framework charter: owner, persona, guardrails).

      

      

        
        
        
        
      

      
Auto setup through a Muse login is on the roadmap. Today, the copy and paste handoff above is how the agent is created in Muse.
