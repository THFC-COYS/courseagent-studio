CourseAgent Studio

Turn a course syllabus into a governed course agent. Design it for Muse and any agent platform, charter it with the AGENT Framework, and publish it with its guardrails attached.

Muse first Governance first Hint-only tutoring Syllabus-bound answers

Start with the syllabus

The agent may only teach what is here. If a topic is not in the syllabus, the agent refuses and escalates. That boundary is the product.

Format: Title: details. The details are the agent's only source material for that topic.

The sample is a fictional course (BIO 210 at the fictional Northgate College), included so you can test the studio in one click.

Configure the agent, then read its charter

Every choice here writes itself into the agent charter on the right. Governance comes first in the charter because governance comes first in the classroom.
